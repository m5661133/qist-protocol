# بوابة التحقّق قبل ترقية Qist (MurabahaV6)

العقد منشور على **Base Mainnet بأموال حقيقية** بنمط UUPS Proxy. خطأ ترقية واحد =
خسارة لا رجعة فيها أو تلف بيانات الـ Proxy. هذه البوابة تمنع ذلك بفحص منهجي قبل
أي ترقية. **لا تتجاوز أي بند، ولا تنشر فعلياً دون إذن صريح من المالك.**

نفّذ البنود بالترتيب، وأبلغ بنتيجة كل بند (✅/❌) مع دليل مختصر.

## 1. الاختبارات تمرّ كاملةً
```
npx hardhat test
```
خط الأساس الحالي **118/118**. أي **نقص** عن العدد = ❌ توقّف (اختبار انكسر أو حُذف).
لا تكمل قبل أن تكون كلها خضراء.

## 2. تطابق ثابت GRACE
قارن `GRACE_PERIOD` في `contracts/MurabahaV6.sol` مع ثابت `GRACE` في `test/*.ts`.
يجب أن يتطابقا تماماً (فخّ موثّق: قيمة الاختبار 180s بدل الإنتاج 259200). إن اختلفا = ❌.

## 3. توافق تخطيط التخزين (UUPS)
```
npx hardhat run scripts/upgrade_base_safe.ts --network base
```
الوضع الافتراضي **تحقّق فقط** (`validateUpgrade`) — يجب أن يطبع «تخطيط التخزين متوافق».
أي تحذير storage layout = ❌ توقّف فوراً (تلف بيانات محتمل). تذكّر: المتغيّرات الجديدة
**تُلحَق في النهاية فقط**، لا تُعاد ترتيباً ولا تُحذف.

## 4. البناء نظيف
```
npx hardhat compile
```
بلا أخطاء.

## 5. قائمة الأمان السريعة (راجع الكود المتغيّر)
راجع `git diff` للتغييرات منذ آخر نشر، وتحقّق:
- **إعادة الدخول / CEI:** تحديث الحالة قبل أي تحويل خارجي · `nonReentrant` على الدوال المالية.
- **الصلاحيات:** كل دالة حسّاسة محميّة (`onlyOwner`/`onlyKeeperOrOwner`) · `_authorizeUpgrade` محمي.
- **أمان الترقية:** `initializer`/`reinitializer` لا يُستدعى مرتين · لا تهيئة implementation مكشوفة.
- **الأوراكل (Base = L2):** فحص `sequencerUptimeFeed` فعّال للأصول غير المستقرة · staleness.
- **الحساب:** لا قسمة قبل ضرب في الربح/الرسوم · التقريب لا يضرّ البروتوكول.
- **التحويلات:** `SafeERC20` · ETH بنمط pull.

## 6. تذكير مزامنة ABI (إن تغيّرت توقيعات الدوال)
إن أُضيفت/عُدّلت دوال عامة، ذكّر بتحديث:
- `../موقع الويب/src/configV6.js` (أو الموقع النشط)
- `../تطبيق الهاتف/lib/contracts/abi.dart`

## 7. بوابة النشر (H2 + الأمان)
- **لا تنشر/ترقّي على Mainnet دون إذن صريح من المالك** — هذه البوابة تتحقّق فقط.
- بعد الترقية الفعلية: المالك يستدعي `setSequencerUptimeFeed` بعنوان feed سيكوينسر Base
  (يُؤكَّد من توثيق Chainlink) لتفعيل فحص H2.
- لا تُرفع الأسرار أبداً (`.env`/المفتاح الخاص).

## الحكم النهائي
اختم بحكم واضح:
- **✅ جاهز للترقية** — كل البنود خضراء (والنشر بقرار المالك).
- **❌ لا ترقّ بعد** — مع ذكر البند الفاشل والسبب.
